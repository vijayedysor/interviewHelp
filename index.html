React live coding round: prep sheet

Questions that match your JD: React core, hooks, Redux, REST, JWT, performance, plain JavaScript, TypeScript and Git. Type each one from memory, then say your approach out loud.

How to run a live round

  • Clarify first. Ask about edge cases, empty states and whether styling matters.
  • Get it working, then improve. Naive version first, then loading and error states, then optimisation.
  • Narrate. State why you pick useReducer over useState, or useMemo over a plain variable.
  • Name the traps. Stable key, effect cleanup, stale closures, dependency arrays, no state mutation.
